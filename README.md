# Ivory Pitches

Static pitch presentations by Ivory Creative Studio, one folder per pitch, deployed on Vercel.

Site files live in `public/`. Run `npm run dev` for a local preview.

- `/epo-in-motion/` – EPO in Motion (EPO 50 anniversary film concept)
- `/epo-in-motion-v2/` · EPO in Motion, alternative version (14 slides, sharper dramaturgy)
- `/epo-in-motion-v3/` · EPO in Motion v3 (original plus the strongest elements of v2)
- `/byd-zero-degrees/` · BYD Zero Degrees (vertical adventure series, Iceland)
